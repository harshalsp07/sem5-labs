📖 Monopoly AI Architecture & Rules

🧠 Game Tree (Expectiminimax) AI Engine

Monopoly is a stochastic game with alternating player choices (deterministic decision nodes) and random dice rolls (stochastic chance nodes). This project models decision-making with an Expectiminimax Game Tree:

  • MAX Nodes (AI Turn): The AI evaluates all available legal actions (Buy, Pass, Upgrade Houses, Mortgage, Unmortgage, Jail Release).
  • CHANCE Nodes (Dice Rolls): Evaluates outcomes over all 11 possible roll values (2 through 12) weighted by binomial probability $P(d) = \frac{6 - |7 - d|}{36}$.
  • MIN Nodes (Opponent Turns): Evaluates opponent counter-actions and future rent payments.

⚖️ State Evaluation Heuristic Function

At the search horizon, states are scored using dynamic weighted features:

V(s) = w_cash · Cash + w_prop · PropertyEquity + w_mono · Monopolies + w_dev · HouseROI + w_inc · E[RentIncome] - w_haz · E[RentHazard]

Dynamic Strategy Adaptation: Weights shift dynamically between Early Game (rapid expansion/land grab), Mid Game (monopoly completion & 3-house sweet spot), and Late Game (liquidity preservation & staying in jail to avoid high-rent hotels!).
