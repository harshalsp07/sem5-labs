# Semester 5 Labs & Coursework (IIT Bhilai)

Repository containing lab assignments, projects, and practical coursework for Semester 5 (Computer Science and Engineering).

## 📚 Courses

| Directory | Course | Description |
| :--- | :--- | :--- |
| [`ai/`](./ai) | **Artificial Intelligence** | Search algorithms (A*, BFS, DFS), games, Prolog, and assignments |
| [`comdesign/`](./comdesign) | **Compiler Design** | Lexer, parser, assembly code generation, MiniC compiler |
| [`dbms/`](./dbms) | **Database Management Systems** | SQL solutions, schema design, database queries, and applications |
| [`nlp/`](./nlp) | **Natural Language Processing** | Language models, POS tagging, translation, seq2seq models, group assignments |
| [`os/`](./os) | **Operating Systems** | IPC, shell implementations, multithreading, Pintos, and xv6 labs |
