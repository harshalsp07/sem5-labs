Task 4: 

Modify the existing Priority Scheduler to implement aging.

The original rule is:

Smaller priority number = higher priority.
Select the READY process with the smallest priority.

Add the following aging rule:

Calculate how long each READY process has been waiting:

waiting_time = current_time - arrival_time;

For every 3 time units of waiting, improve its priority by 1:

effective_priority = priority - waiting_time / 3;
The effective priority must never be less than 1.
Select the READY process with the smallest effective priority.
Do not modify the original p->priority; calculate the effective priority temporarily.
